# REGOLE

Una funzionalità può passare dal BACKLOG alla ROADMAP solo se:

- è stata approvata
- ha un ROI positivo
- è compatibile con l'architettura
- non aumenta inutilmente i costi server
- migliora concretamente l'esperienza utente

BACKLOG e ROADMAP devono rimanere separati.
